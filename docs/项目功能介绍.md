# 糍粑听歌学英语（ciba-music）项目功能介绍

> 一款「听英文歌学英语」的跨平台 App（React Native + Expo + EAS）。
> 把**歌曲播放 / 歌词学习**与**生词本 / 背词（Anki 式间隔复习）**深度结合。

---

## 一、产品定位与导航结构

- 底部三大 Tab：**首页**、**生词本**、**我的**（`src/components/TabBar.tsx`）。
- 其余页面（播放、歌词学习、听力/跟读、AI、词库、会员等）以详情栈（push）方式打开，返回即出栈。
- 通用交互规范：确认/提示统一用自研 `ConfirmDialog` / `ActionSheet`（不用系统 `Alert`）；轻提示用 `showToast`。

---

## 二、听歌学英语（音乐播放与歌词学习）

### 首页（HomeScreen）
- 按时段问候语。
- 顶部搜索：按名称 / 歌手 / 专辑过滤精选歌单。
- 「生词本」进度卡片：今日目标 / 已学习 / 总词数、百分比。
- **最近播放**横滑列表（`recentPlays`）：点击直接续播、可清空。
- 精选歌单列表展示。
- 未登录统一引导登录。

### 播放页（PlayerScreen）
- 播放 / 暂停 / 上一首 / 下一首。
- 进度条与歌词实时高亮。
- **显示 / 隐藏中文译文**并记住选择（`AsyncStorage` 持久化）。
- 切换译文显隐时当前歌词行重新对位（修正焦点位置）。
- **随机播放 / 循环**按钮点击弹 toast 提示当前模式。
- 试听片段（Apple Music 未订阅）与全曲（已订阅）两种音源。
- **自然播完自动下一首**：原生层 `finishedFired` 防重复 + 进度到末尾兜底（部分 iOS 版本 MusicKit 末句不切 `stopped`）。


### 查词卡片（WordLookupCard）
- 播放页 / 歌词页点单词弹出的查词 `Modal`。
- 音标（英音 / 美音，点一下发音）、词性释义、首条例句。
- 底部「添加到生词本」，成功后关闭弹框（`onClose()`）。

### 本首歌学习要点（VocabScreen）
- 列出该曲重点单词语法、短语搭配，修辞、句型等知识点。


### 添加歌曲到歌单（SearchSongScreen）
- 通过 Apple Music（MusicKit）搜索歌曲，`+` 号加入歌单。
- 接口返回慢时按钮显示转圈（`ActivityIndicator`）并防重复点击，成功提示「歌词翻译生成中」。

### 歌单详情（CollectionDetailScreen）
- 播放全部、歌单歌曲列表（分页加载）。
- 个人歌单（VIP）可搜索加歌，免费用户仅显示前 N 首并常驻升级引导。

## 三、生词本与背词（Anki 式间隔复习 SRS）

### 生词本（BookmarksScreen）/ 生词本学习（BookmarkStudyScreen）
- 已收藏单词的管理与复习入口（从糍粑主 App 移植的成熟逻辑）。

### 闪卡（FlashcardScreen）
- 卡片翻转、英 / 美音朗读。
- 按记忆程度 4 档打分（稍后重来 / 1 天 / 3 天 / 7 天），驱动艾宾浩斯复习曲线。

## 五、账户、会员与权益门禁

### 登录注册（auth/*）
- 登录、注册、忘记密码、修改密码（手机号 / 账号体系）。

### 个人中心（ProfileScreen）
- 用户信息与 VIP 状态（VIP / 免费 / 游客）。
- 学习统计（连续打卡、已掌握单词）。
- **生词本每日学习目标**（快捷档位 + 自定义，乐观保存）。
- **发音偏好**（美音 / 英音切换、进入新词自动朗读）。
- 用户协议 / 隐私政策（`WebPage` 打开）。
- **注销账号**两步确认（符合苹果 5.1.1(v)）。

### 会员开通（PurchaseScreen）
- Apple 内购订阅自动续费。
- 服务端价签下发套餐、价格只取 StoreKit `displayPrice`。
- 票据交服务端校验（含二次确认会员是否真的开通，防掉单）。
- **恢复购买**、**管理订阅**；非人民币区币种提示。

### VIP 权益门禁（vipGate）
- 免费 / 未登录用户受限——如往歌单加歌、全曲播放等会引导开通会员。

### Apple Music 订阅检测（appleMusic.ts + 原生模块）
- 三态（已订阅 / 可引导 / 读不到），首页非阻断引导订阅。

## 六、通用能力与技术底座

- **最近播放（recentPlays）**：本地存储、横滑、一键清空，播放即写入。
- **添加歌曲缓存（addedSongsCache）**：加歌成功后乐观缓存，详情页合并兜底。
- **发音能力（speech / wordAudio）**：英音 / 美音 TTS 朗读单词与句子。
- **播放器后端抽象（player/）**：`preview`（expo-av 试听）与 `appleMusic`（MusicKit 全曲）实现同一 `PlayerBackend` 接口，按可用性自动选源；原生模块 `modules/apple-music-player`（Swift）负责 MusicKit 播放与「自然播完」识别。
- **工程化**：EAS 云端构建（无需本地 Xcode）出 iOS(.ipa) / Android(.apk)，支持 Web 端直接预览。
- **设计系统**：糍粑风格（琥珀橙 + 米白 + 风车四色），统一卡片 / 圆角 / 间距。

## 七、目录结构速览

```
src/
  screens/          # 所有页面（首页/播放/歌词/生词本/词库/听力/跟读/AI/会员/登录注册…）
  components/       # TabBar、ConfirmDialog、ActionSheet、WordLookupCard、Header 等
  services/         # musicApi、wordApi、bookmarkApi、payApi、packLibrary、appleMusic、vipGate…
  storage/          # recentPlays、addedSongsCache、progressStore（学习进度/设置）
  context/          # AuthContext（登录态）、Progress 等
  player/           # 播放器后端抽象（preview / appleMusic）
  hooks/            # 通用 hooks
modules/
  apple-music-player/  # iOS 原生 MusicKit 播放模块（Swift）
docs/
  项目功能介绍.md     # 本文档
```
